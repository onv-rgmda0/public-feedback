# 專案公開回饋與資料倉庫

⚠️ **本倉庫不包含任何原始程式碼**  
此處為組織對外的公開窗口，僅用於：

- 提交 **Bug 回報** 與 **功能建議**
- 存放 **已去識別化的公開參考資料**（如使用者手冊、更新紀錄、FAQ 等）

所有實際開發工作均在私有程式碼倉庫進行，此處僅為溝通與文件匯集點。

## 開始之前

為避免重複通報與混亂，請先：

1. 搜尋現有 Issue，確認是否已有相同或相似的回報。
2. 認清本倉庫用途屬於**公開**空間，以下內容**嚴禁出現**：
   - 任何形式的程式碼（片段、截圖、壓縮檔皆不行）
   - 可識別的車型專案代碼、客戶名稱、內部系統網址
   - 密碼、Token、API 金鑰或個人資料
   - 敏感商業策略與未公開設計細節
3. 所有討論請在 Issue 中進行，切勿透過其他管道傳送代碼截圖或機敏附件。

## 🐞 回報 Bug

請使用以下範本建立新 Issue，並盡可能提供完整資訊：
問題描述
（簡述你遇到的問題）

重現步驟
前往 '...'

點選 '....'

執行 '....'

出現錯誤

預期結果
（你預期應該發生什麼事）

實際結果
（實際上發生了什麼事，包含錯誤訊息或異常行為）

環境資訊
裝置 / 車型（僅提供不具識別性的資訊，如「Android 13 平板」、「2024 年式測試車」）

系統或應用程式版本

網路環境（Wi-Fi / 行動數據 / 離線）

**注意**：如果環境資訊可能間接暴露車型專案代碼，請自行模糊處理（例如以「A 平台」、「內部測試環境」代替）。

## 📂 提供公開資料

本倉庫亦接受**非敏感性的公開文件與資料**，例如：

- 使用者操作手冊（對外公開版）
- 版本更新紀錄（Release Notes，已去識別化）
- 常見問題集（FAQ）
- 公開設計規範或品牌素材（經授權之版本）

**提交方式**：

1. **Fork 本倉庫**並在你的分支中加入檔案。
2. 發起 **Pull Request**，簡述新增內容與目的。
3. 維護者審核通過後合併，內容即成為本倉庫的公開資源。

注意：提交前請再次確認文件內無任何程式碼、內部系統名稱、客戶資訊或未公開數據。一旦合併即視為可公開之資訊。

## 🔒 安全漏洞回報

若你發現可能影響系統安全或資料保護的漏洞，**請勿在公開 Issue 中揭露**。  
請改用以下方式私下聯繫：

- 寄送 Email 至 [security@example.com]（請更換為實際窗口）
- 或透過組織提供的其他安全回報管道

我們會在確認後依責任揭露原則處理。

## 🤝 行為準則

為維持友善的協作環境，所有參與者須遵守以下基本規範：

- 尊重他人，嚴禁人身攻擊、歧視或騷擾言論
- 聚焦於問題與解決方案，避免離題討論
- 不重複發送內容相同或高度相似的 Issue
- 遵守上述機敏資訊規範

#### 違規處理
違反規範者，維護團隊將視情況隱藏、關閉相關 Issue，或予以封鎖。

## ⚖️ 免責聲明

- 本倉庫為**單向回饋與公開資訊集散地**，不保證所有建議皆被採納，也不保證 Bug 修復的具體時程。
- 所有被合併的資料以「現狀」提供，組織對其正確性與完整性不作任何明示或暗示之擔保。
- 若你無法判斷某項資訊是否適宜公開，請先透過 Email 與團隊確認，勿直接上傳。
